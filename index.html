Suggested workflow

  1. Start with the source URL and the intended target URL.
  2. Verify link presence, destination, anchor text, and rel attributes.
  3. Review HTTP response, robots directives, and canonical signals.
  4. Record evidence and classify the result as OK, Needs Review, Blocked, or Missing.
  5. Fix what you control, contact the publisher where appropriate, and recheck later.

Important limitations

  • A crawlable or technically indexable page is not guaranteed to be indexed by Google.
  • A robots.txt block can prevent crawling but does not necessarily prevent a URL from appearing in search results.
  • Canonical tags are signals, not guarantees. Search operators are not a complete index-status API.
  • nofollow, sponsored, and ugc attributes do not prove whether a page is indexed.
  • This checklist does not provide DA/PA metrics or guarantee rankings, link value, or indexing.
